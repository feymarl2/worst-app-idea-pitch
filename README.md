MeetingMeter: the worst app idea ever pitched — it counts how many of your meetings could have been an email, then schedules a weekly meeting to present the results to your entire team in a slide deck.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the pitch to `/output/entry.txt`: UTF-8, 163 characters, byte-identical on every run.
